# Project-basic owner-observed dogfood guide

This guide records scenarios to observe; it does not claim that any scenario has been run or
accepted. In every scenario, preserve the normal claim, check, evidence, verification, and owner
acceptance records for the exact artifact revisions under review.

| Scenario | Expected recommendation and evidence | Owner observation prompts |
|---|---|---|
| Beginner game | Recommend `project-basic`; retain a vision brief, learning profile, prototype evidence, criteria, and evaluation tied to the exact game revision. | Was the vision captured? Were question batches understandable? Did practice differ clearly from review? |
| Scientific or evidence-focused project | Recommend `project-basic` when the research supports a broader project; retain readiness, sources, uncertainty, research, and criteria evidence. | Did the readiness report honestly explain whether new research was needed? Was uncertainty visible? |
| Physical-making project | Recommend `project-basic`; retain sketches/photos/material constraints, task map, created-work evidence, and safety or fit evaluation. | Did the conversation make hands-on constraints clearer without pretending the agent performed the work? |
| Creative writing or song | Recommend `project-basic`; retain the vision, references, draft revision, criteria, evaluation, and review. | Did the guidance protect creative choices while giving useful, bounded teaching? |
| Clear software change | Recommend `software-basic` when vision and context are already clear; retain the software workflow's normal artifacts and verification. | Did routing avoid adding unnecessary project intake while preserving the same owner gates? |

For each observed run, record only owner-observed facts and exact revision identities. Useful
qualitative criteria are: captured vision, improved context, useful questions, appropriate teaching,
delegation support, reduced confusion, and a meaningful improvement over ordinary chat. These are
observation prompts, not automatically enforceable checks or fabricated outcomes.
